# 中文字幕净化、拆条与脚本生成规则

精剪成片字幕（`.srt`）与纯净口播正文（`.txt`）统一由 `scripts/subtitle_processor.py` 根据 `timeline_edit.json` 和 `*_逐字时间.json` 自动生成（内置倍速映射与本机 `glossary` 词汇表读取）。

---

## 一、标准生成命令

```powershell
python -B scripts/subtitle_processor.py `
  --plan "<timeline_edit.json>" `
  --srt "<确认版原SRT>" `
  --chars "<确认版逐字时间JSON>" `
  --out-srt "<视频原文件夹>/<视频名>_精剪字幕.srt" `
  --out-txt "<视频原文件夹>/<视频名>_精剪台词.txt"
```

需要精细处理跨视频切点字幕或剔除句中特定被删字时，传入可选 `--rules "<subtitle_rules.json>"`：
```json
{
  "excluded_srt_ids": [40],
  "cue_overrides": {
    "V03": [{"srt_id": 40, "text": "保留的前半句", "source_start": 85.6, "source_end": 85.92}],
    "V04": [{"srt_id": 40, "text": "保留的后半句", "source_start": 87.04, "source_end": 89.84}]
  },
  "drop_char_ranges": [{"source_start": 86.0, "source_end": 86.9, "reason": "删卡壳词"}],
  "typo_fixes": {"global_replacements": [["错词", "正确词"]]}
}
```

## 二、标点净化与单行长度标准

| 标点类别 | 处理规则 | 示例 |
| --- | --- | --- |
| **句末停顿类**（`，` `。` `；` `：` `、` 及半角） | 剥离不显示 | `局部调整音乐。` -> `局部调整音乐` |
| **情绪语气类**（`？` `！` `…` 及半角） | 保留在条尾 | `可是你知道吗？` -> `可是你知道吗？` |
| **句内逗号 / 分号**（`，` `；`） | 按自然子句拆成独立条 | `完全免费，本地运行。` -> `完全免费` / `本地运行` |
| **顿号 `、`** | 整条宽度 `<= 12` 字换为空格同条显示；`> 12` 字沿顿号拆条 | `舒服、耐磨。` -> `舒服 耐磨` |
| **成对限定符**（`“ ”` `《 》` `——` `·`） | 成对完整保留，不断开 | `《剪辑方法论》` |

- **视觉宽度折算**：中文全角字符计 `1.0`，ASCII 字母、数字与半角符号计 `0.45`。
- **单行长度上限**：竖屏 `9:16` 理想 `6~12` 字、硬上限 `13` 字；横屏 `16:9` 理想 `8~14` 字、硬上限 `16` 字。

## 三、真实字界拆条、防闪屏与剪映样式

1. **按真实逐字时间拆条**：优先落在字间微气口（`>= 0.06s`），其次按中文语法短语边界拆分，自动保护本机 `glossary.terms` 中的人名/品牌/专业名词与英文数字整体。
2. **防闪屏与阅读延尾**：清理 `< 0.45s` 的孤立语气词短条，相邻实词短条自动合并或安全延尾；默认条尾增加 `0.18s` 阅读缓冲，严格不跨越视频切点且与下一条保持 `>= 0.02s` 零重叠。
3. **剪映原生默认样式**（`execute_timeline_edit.py --target jianying --srt "<精剪字幕.srt>"` 自动应用）：
   - 竖屏 `9:16`：`size = 7.0`，`transform_y = -0.60`，居中单行，黑色外描边 `width = 40.0`；
   - 横屏 `16:9`：`size = 6.5`，`transform_y = -0.78`，其余同上。

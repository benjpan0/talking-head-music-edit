# 口播去重纠错、合并定刀与方案汇报

按“通读全片 → 词汇表与原稿纠错 → 顺畅合并与定点删减 → 对话正文汇报方案 → 确认后产出文件”执行。

---

## 一、核心原则：顺畅多句合并为长片段，只在删减处下刀

1. **连续顺畅表达合并为 1 个长片段**：凡是连续多句或数十秒内表达通顺、无重录、无卡壳、无超长看稿死气（`> 1.5s`）的区间，整体保留为 1 个完整的视频片段（例如 `V01: 0.00s ~ 28.40s`）。
2. **只在真正剔除内容的位置断开**：仅当出现下方 4 类需删减情况（整句重录、句内卡壳、按档位需删的孤立语气词、超长看稿死气）时才落刀。正常 2~3 分钟口播，全片切点通常在 **5~15 刀** 左右。
3. **合并自检**：写出 `timeline_edit.json` 前检查相邻视频段——若同素材相邻两段在原片中仅差 `< 0.15s` 且中间没有删掉任何重录或废词，直接合并为同一段。

---

## 二、三层时间锚定机制

联合三层证据定刀，保证切点干净不吞字：
1. **宏观语义层（`.txt` / `.srt`）**：识别跨句重录、重复解释与结尾多版本。
2. **微观刀口层（`*_逐字时间.json`）**：精确到具体单字的 `(text, start_time, end_time)`。
3. **声学物理层（`scan_report.json`）**：对照 `-35dB / 0.12s` 常规静音与 `-28dB / 0.05s` 微气口，切点优先落在静音区中段。

---

## 三、词汇表复用、原稿对比与 4 类去重规则

### 1. 常用词汇表与错字校正
- 先套用本机 `glossary.replacements` 预筛高频误识词，并结合 `glossary.terms` 核对人名、品牌与专业名词。
- 有原稿时直接对照 `.srt` 与原稿找出错词；无原稿时按实录语义核对明显同音错字。只修正已念出词的文字，保留实录语句原貌。
- 确认后用 `scripts/correct_transcript.py apply` 同步回写 `.srt` 与 `*_逐字时间.json`（只改文字，保持音轨时间点不变）。
- **新词沉淀**：将用户本次新纠正的人名、品牌、专业名词或固定错词，立即通过 `python -B scripts/init_machine.py --save --add-replacement "错词=正确词"` 写入本机常用词汇表。

### 2. 渐进式重录与整句重说
- 前一遍半句中断或磕绊、后一遍完整顺畅重说时，整体保留最后一遍完整版本，剔除前面试探句，保持单遍完整语调。

### 3. 句内卡壳回退与局部自修
- 仅句中卡壳且未重念整句时，查 `-28dB` 微气口：存在 `>= 0.05s` 物理空隙则定点删掉卡壳词并紧接；完全连读粘死时保留原连贯音轨或整句替换。

### 4. 语气废词与同义结尾择优
- 孤立 `呃`、`嗯`（`0.08s ~ 0.30s`）按所选档位在音轨中剪除，字幕中统一清理。
- 结尾录了 2~3 版相似收束时，按完整度与干脆度择优保留最流畅一版。

## 四、场景气口校准与切点细则

| 内容场景 | 目标气口（相对本片原生基线） |
| --- | --- |
| **句内修补 / 主谓宾重接** | 紧接顺流（`0.08s ~ 0.18s`），保持单句一口气感 |
| **短词并列 / 紧凑推进** | 贴近本片短顿下限（`0.15s ~ 0.44s`） |
| **常规叙事顺承** | 对齐本片原生常态换气，与前后两句同频 |
| **转折设问 / 核心概念落地** | 保留完整反应与消化留白，超 `1.8s` 的看稿等待收紧回正常上限 |

- **双向借气口**：原停顿过长时，前句尾与后句头各留半个自然气口；删重录后偏紧时，在发声边界外的静音区适度外扩。
- **句间留尾韵**：完整句拼接保留前句 `0.15s ~ 0.45s` 尾音下沉与后句起音准备空间。
- **零时长伪字界处理**：遇到 `start_time == end_time` 的对齐字，结合相邻真实发声字与 `-28dB` 静音区定刀。
- **避免高频连跳**：2 秒内连续两个极轻微语气停顿，优先合并保留连贯短语，减少视觉高频跳切。

## 五、对话正文简洁汇报模板与产物输出

1. **在对话正文直接按以下简洁模板汇报（控制在 15 行左右，只列重点，等用户确认）**：

```markdown
### 口播分析与剪辑确认
- **语速评分**：`XXX 字/分`（偏慢/适中/偏快）｜**建议倍速**：`1.0x / 1.1x`
- **请选择剪辑档位**：`1) 平衡型（默认）` / `2) 专业紧凑型` / `3) 人性化口播型`
- **拟纠错字**（无则写“无”）：`错词1 → 正确词1`、`错词2 → 正确词2`
- **剪辑概览**：原片 `XXs` → 预计成片 `XXs`｜合并保留 `X` 大段（共切 `X` 刀，主要剔除：`一句话概括几处重录/长停顿`）｜人声音量：`1.0`
- **输出目标**：`<剪映草稿目录 / ADu / FFmpeg / 仅方案>`

请回复确认：**档位（1/2/3）+ 是否加速 + 是否按以上方案剪辑**。
```

2. **确认后产出 3 份文件（保存在视频原文件夹）**：
   - `timeline_edit.json`（含 `tracks.video`）；
   - 运行 `python -B scripts/subtitle_processor.py --plan "<timeline_edit.json>" --srt "<确认版SRT>" --chars "<确认版逐字JSON>" --out-srt "<视频名>_精剪字幕.srt" --out-txt "<视频名>_精剪台词.txt"`，同步生成友好精剪 `.srt` 与 **100% 纯净纯文本 `.txt`**（仅含最终成片口播的干净中文正文与正常标点）。

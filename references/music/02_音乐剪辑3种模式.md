# 音乐剪辑 3 种标准模式（配乐落轨规则）

确认歌曲后，按口播文案的段落时长与转折节点，从以下 **3 种标准模式** 中选择并循环组合，写入 `timeline_edit.json` 的 `tracks.audio`（双音轨交叉与坐标字段规则见 [01_时间线执行格式与交付](../01_时间线执行格式与交付.md)）。

---

## 一、3 种标准剪辑模式

### 模式 1：两段式（主段 + 结尾）
- **结构**：截取原曲合适长度的主体段 → 接原曲结尾（或衰减淡出收尾）。
- **适用**：15~30 秒左右的短段落、快节奏开场或局部垫乐。
- **衔接**：主体与结尾不连续时，在接点处使用默认 `0.5s` 双音轨交叉淡入淡出。

### 模式 2：三段式（开头 + 中间推进/循环 + 结尾）
- **结构**：保留原曲开头起手 → 中间按文案总长度衔接主体/推进段 → 接原曲结尾收住。
- **适用**：30 秒以上的完整口播段落或全片主配乐。
- **衔接**：原曲相邻段本来连续时保持原演奏不断开；跳接时使用双音轨交叉淡入淡出。

### 模式 3：停顿留白再续（转折截断 / 高音停顿）
- **结构**：在文案的**转折句、抛问句、金句或高音节点**处果断截断音乐 → 按文案内容留白停顿 `N` 秒 → 从原曲**紧接着的断点位置**（或下一乐句起势点）续播。
- **关键参数**：
  - 截断处加 `0.15s ~ 0.30s` 短淡出防爆音；
  - 停顿时长 `N` 由口播重点台词决定（通常 `1.0s ~ 3.0s`）；
  - 连续断点续播时设 `后段 source_start = 前段 source_end`（可加 `0.05s ~ 0.15s` 短淡入），保持旋律连贯感。

---

## 二、文案节奏到落轨步骤

1. 对照精剪 `.srt` 划分音乐窗口（如：`0~4s` 留白、`4~42s` 主叙述、`42~44.5s` 转折停顿、`44.5~90s` 总结升华）。
2. 为每个窗口选定模式 1/2/3，结合 `_剪辑数据.json`（或调用 `scripts/auto_music.py --mode plan`）定出每段原曲起止点。
3. 音量默认取 `music_catalog.json` 中的 `default_volume`（口播期间常见 `0.15 ~ 0.22`），交叉淡入淡出按 `track: 0` 与 `track: 1` 交替写入 `timeline_edit.json`。

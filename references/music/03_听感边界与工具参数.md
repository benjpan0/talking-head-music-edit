# 音乐听感边界与 `auto_music.py` 工具参数

## 一、入口、接缝、发展与结尾听感标准

1. **入口**：分别决定原曲哪里起、成片哪里进、是否渐入。优先尝试原录音 `0s` 开头；若从内部切入，向前检查重拍前是否存在弱起前导音，将前导纳入源区间。中途硬切进入时用短渐入测试，避免长淡入吃掉第一下鼓点或主音。
2. **接缝**：检查拍号/相位、配器、音色、和声走向与响度。先找两段内容能顺接的拍点，再在两侧留交叉余量，拦截双重音、节拍错位、半句旋律与响度塌陷。默认内部交叉淡化 `500ms`。
3. **发展**：口播期间避免乐器过密遮挡人声；起势需有实际推进感，高潮留给观点揭示或画面落点；原曲本来连续发展的段落直接连留，不做多余拆切。
4. **结尾**：区分最后完整演奏、衰减余韵与纯静音；可比较“保留真实收束”“衰减区淡出”“明确段落截断”三种方式。纯防爆音短淡出不能替代音乐终止感。
5. **验听**：同一监听电平分别听入口、每个接缝、主体、结尾，以及叠上口播人声后的清晰度。

## 二、`scripts/auto_music.py` 输入与调用参数

用于基于真实原曲与毫秒制 `_剪辑数据.json`（`schema: tingdong_edit_report`，`time_unit: ms`）自动搜索自然接缝、多阶段候选或直接渲染单曲。

### 常用命令
```powershell
# 精确总长方案（输出 剪辑方案.md 与 剪辑方案.json）
python -B scripts/auto_music.py "<_剪辑数据.json>" --mode plan --duration 18.5 --entry-mode original --strategy auto --crossfade-ms 500 --candidates 2

# 多阶段参考时长方案（各阶段秒数为软偏好；若需硬总长则额外加 --duration）
python -B scripts/auto_music.py "<_剪辑数据.json>" --mode plan --stages "平静:6,起势:4,高潮:4,收尾:6" --entry-mode auto --strategy auto --crossfade-ms 500 --candidates 2

# 直接导出音频（WAV + MP3 + 剪辑点建议.md）
python -B scripts/auto_music.py "<_剪辑数据.json>" --mode audio --duration 18.5 --entry-mode original --strategy auto --crossfade-ms 500 --candidates 2
```

### 核心参数表

| 参数 | 说明 |
| --- | --- |
| `analysis_json` | 必填，毫秒制 `_剪辑数据.json`（拒绝秒制原始 JSON） |
| `--mode plan\|audio` | 必填，`plan` 只出方案，`audio` 直接渲染 WAV/MP3 |
| `--duration` | 普通模式必填（精确总长，秒）；多阶段模式可选 |
| `--stages` | 2–8 个有序阶段 `角色:参考秒数`（可用：`calm/平静`、`rise/起势`、`climax/高潮`、`sustain/持续`、`release/回落`、`ending/收尾`） |
| `--audio` | 可选，显式指定原音频路径（覆盖 JSON 内失效路径） |
| `--entry-mode auto\|original\|fade` | 默认 `auto`；`original` 严格从原曲 `0s` 起；`fade` 柔和渐入 |
| `--strategy auto\|opening\|ending` | 默认 `auto`；`opening` 开场附近取材；`ending` 尽量保留原尾 |
| `--crossfade-ms` | 默认 `500`，须大于 `0` 且严格小于目标时长一半 |
| `--fade-in-ms` | 可选，显式固定开头淡入时长（`0` 表示关闭） |
| `--candidates 1\|2\|3` | 默认 `2`，整首剪后音乐的候选方案数 |
| `--output` | 可选，默认在原音频目录下新建独立结果子目录（不覆盖已有目录） |

## 三、常见异常与约束处理

- **找不到原音频**：提示缺源或用 `--audio` 指定真实路径，严禁仅凭 JSON 伪造音频。
- **JSON 格式不符**：要求提供 `tingdong_edit_report` 毫秒制 `_剪辑数据.json`，不猜测单位。
- **目标长于原曲**：说明单曲搜索只做缩短；配乐铺长片时按 [02_音乐剪辑3种模式](02_音乐剪辑3种模式.md) 拆段循环铺轨。
- **硬约束冲突**（如 `original` + `ending` + 精确时长无法同时成立，或交叉淡化超过目标一半）：如实报告无可行候选，由用户决定放松哪项约束，不暗改参数。

# 初始化配置与素材转写

以下命令均从技能根目录运行。基础环境需要 **Python 3.10+**、**FFmpeg / FFprobe**（音乐计算另需 **NumPy**，见 `requirements.txt`）。

---

## 一、环境检查与常用配置保存

### 1. 检查本机状态
```powershell
python -B scripts/init_machine.py --inspect
```
查看返回中的 `initialized_complete` 与 `missing_required_fields`。发现缺少 Python / FFmpeg / NumPy 时，向用户列出缺项并协助安装。

### 2. 确认并保存本机配置
配置结构见 [user_profile.example.json](../assets/user_profile.example.json)，默认保存在 Windows 的 `%LOCALAPPDATA%\talking-head-music-edit\machine_profile.json`。

向用户一次问清所有缺失项后保存：
1. **剪映草稿真实目录**：核对探测到的 `drafts_root` 是否为当前使用的剪映草稿目录，确认准确路径后写入 `--drafts-root`（与可选 `--root-meta`）。
2. **逐字时间戳识别方式**：`faster-whisper`（本地离线）/ `API`（百炼、腾讯云、Groq、OpenAI 兼容）/ `qwen3-asr`（指定本地程序目录）。
3. **音乐库根目录**：写入 `--music-lib` 并执行第二节的规范检查。
4. **常用习惯与音量**：保存默认剪辑档位（`balanced` / `compact` / `natural`）、口播人声音量（默认 `1.0`）、配乐底音量（默认 `0.18`）、默认交付方式（`jianying` / `adudir` / `ffmpeg` / `plan` / `both`），并可按视频类型写入 `presets_by_type`。

```powershell
# 保存基础初始化配置
python -B scripts/init_machine.py --save --asr-mode faster-whisper --drafts-root "<剪映真实草稿目录>" --music-lib "<音乐库目录>" --default-style balanced --speech-volume 1.0 --music-volume 0.18 --editor-target jianying

# 追加用户常用词汇（纠错后自动沉淀）
python -B scripts/init_machine.py --save --add-term "专有名词" --add-replacement "错词=正确词"

# 保存按视频类型的常用习惯（支持 JSON 字符串或 JSON 文件路径）
python -B scripts/init_machine.py --save --save-preset '{"知识观点":{"speech_style":"balanced","default_speed":1.0,"speech_volume":1.0,"music_volume":0.18,"delivery":"jianying","auto_confirm":true}}'
```

## 二、音乐库标准文件夹与自动整理

音乐库根目录采用固定 3 项结构：

```text
<音乐库根目录>/
├── audio/                  # 音乐源文件（.mp3 / .wav / .flac / .m4a / .aac）
├── analysis/               # 对应分析文件（<歌名>_剪辑数据.json）
└── music_catalog.json      # 快速配对索引（格式见 assets/music_catalog.example.json）
```

```powershell
# 只读检查目录规范
python -B scripts/check_music_library.py --dir "<音乐库目录>" --check

# 归位散落文件并生成或补全 music_catalog.json（保留已有自定义标签）
python -B scripts/check_music_library.py --dir "<音乐库目录>" --organize
```
整理完成后，为新增曲目补全 `mood`（情绪）、`scenes`（适合场景）与 `preview_segments`（试听段）。

## 三、逐字识别、纠错回写与静音扫描

### 1. 生成逐字时间戳（保存在视频原文件夹）
已有同源且匹配的 `.srt` 与 `*_逐字时间.json` 时直接复用；否则运行：
```powershell
python -B scripts/transcribe_talking_head.py --input "<源视频>" --out-dir "<源视频所在文件夹>" --backend auto
```
默认产出 `<视频名>.srt` 与 `<视频名>_逐字时间.json`。

### 2. 错字无损同步回写
确认完错字清单后，将修正写入 `corrections.json`（格式：`{"cue_fixes":{"12":"修正后整句"},"global_replacements":[["错词","正确词"]]}`），同步更新两份文件：
```powershell
python -B scripts/correct_transcript.py apply --srt "<原SRT>" --chars "<原逐字JSON>" --corrections "<corrections.json>" --out-srt "<确认版SRT>" --out-chars "<确认版逐字JSON>"
```
（仅在长稿需要辅助找差异时可选用 `correct_transcript.py inspect --srt "<SRT>" --ref "<原稿>"`。）

### 3. 静音与原生节奏扫描
```powershell
python -B scripts/scan_talking_head.py --video "<源视频>" --srt "<确认版SRT>" --chars "<确认版逐字JSON>" --out "<scan_report.json>"
```
输出真实视频流宽高/帧率/时长、双阈值静音窗（`-35dB` 与 `-28dB`）、`native_pause_baseline` 及零时长字警告。

## 四、逐字识别后端选型参考

| 方案 | `--backend` | 适用条件 | 准备要求 | 注意点 |
| --- | --- | --- | --- | --- |
| 阿里云百炼 | `dashscope` | 零显卡、国内直连 | `DASHSCOPE_API_KEY` + `websockets`/`aiohttp` | 默认 `paraformer-realtime-v2`，原生毫秒词级时间戳 |
| 腾讯云极速版 | `tencent` | 零显卡、国内直连 | `TENCENTCLOUD_APPID` / `SECRET_ID` / `SECRET_KEY` + `requests` | 内置 `word_info=1`，超 5 分钟自动按静音分片 |
| Groq / OpenAI 兼容 | `groq` / `openai` | 零显卡、海外或自建 API | `GROQ_API_KEY` 或 `OPENAI_API_KEY` + `requests` | 自动压为 16kHz 单声道 MP3 提取 `words[]` |
| 本地离线 Whisper | `faster-whisper` | 离线/隐私优先、CPU 或 N 卡 | `python -B scripts/bootstrap_faster_whisper.py --download-model small` | 独立缓存于外部目录；缺 CUDA DLL 自动降级 CPU `int8` |
| 指定本地程序 | `qwen3-asr` | 本机已有 `Qwen3_ASR` 与 N 卡 | `--qwen3-dir` 指定路径 | 调用 `batch_transcribe.py --save-timestamps` |

### `*_逐字时间.json` 统一契约
- 只保留核心文字单元（中文按单字、连续英文/数字按整词）。
- 多字词时间戳按字线性均分且单调非递减；若后端标记 `estimated_word_timestamps: true`，切点须完全依据 `scan_report.json` 的物理静音边界。

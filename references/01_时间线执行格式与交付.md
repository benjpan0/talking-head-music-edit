# 主时间线执行格式与交付（`timeline_edit.json`）

`timeline_edit.json` 是导演决策完成后交给 **剪映草稿**、**ADu 工程**、**FFmpeg 直出** 或 **其他剪辑智能体** 的统一中间执行文件。

- 只写**怎么摆时间线**，不写“为什么这样剪”。
- 只包含 **2 类轨道**：视频（`tracks.video`）和音频（`tracks.audio`）。
- 全部时间统一用**秒**（保留 2 位小数）。
- 完整示例见 [timeline_edit.example.json](../assets/timeline_edit.example.json)，字段校验定义见 [timeline_edit.schema.json](../assets/timeline_edit.schema.json)。

---

## 一、字段说明

1. **`project`**：`name`（工程名）、`width`（宽）、`height`（高）、`fps`（帧率）。
2. **`assets`**：给每个用到的素材起短编号（如 `v1`、`a1`），写 `type`（`video` / `audio` / `image`）和 `path`（绝对路径或相对本 JSON 路径）。
3. **`tracks.video` 与 `tracks.audio`**（两类轨道片段字段完全一致）：

| 字段                              | 必填  | 默认值 | 说明                                             |
| --------------------------------- | :---: | :----: | ------------------------------------------------ |
| `id`                              |  是   |   —    | 片段编号（如 `V01`、`A01`），文件内不重复        |
| `track`                           |  是   |   —    | 轨道编号，从 `0` 开始（`0` 主轨，`1` 第二条轨）  |
| `asset`                           |  是   |   —    | 素材编号（对应 `assets` 中的键）                 |
| `timeline_start` / `timeline_end` |  是   |   —    | 在主时间线上从第几秒开始、到第几秒结束           |
| `source_start` / `source_end`     |  是   |   —    | 切取原素材从第几秒开始、到第几秒结束             |
| `speed`                           |  否   |  `1`   | 倍速（原速 `1`，加速 `1.1`）                     |
| `volume`                          |  否   |  `1`   | 音量（原音 `1`，静音 `0`，配乐常见 `0.15~0.25`） |
| `fade_in` / `fade_out`            |  否   |  `0`   | 淡入 / 淡出时长（秒），`0` 表示不淡入/淡出       |

---

## 二、轨道与双音轨交叉淡入淡出规则

1. **同轨不重叠**：同一个 `track` 编号内，后一段的 `timeline_start >=` 前一段的 `timeline_end`。
2. **双音轨交叉淡入淡出**：需要两段音乐交叉淡入淡出时，将前后两段错开放到 `track: 0` 与 `track: 1`（多段连续交叉时 `0 → 1 → 0 → 1` 交替），重叠时长等于前段 `fade_out` 与后段 `fade_in`。
3. **停顿留白再续**：文案转折处需要音乐突然停顿 N 秒再继续时，前段在截断点短淡出（`0.15~0.3s`），留出 N 秒空白，后段从原曲紧接着的位置继续播。
4. **时长与倍速一致**：非图片素材满足 `(source_end - source_start) / speed ≈ (timeline_end - timeline_start)`。

## 三、4 种交付方式与执行命令

统一由 `scripts/execute_timeline_edit.py` 执行，每次执行都会在输出目录自动生成一份人话版 **`操作指引与剪辑说明.md`**（含可直接复制给智能体的引导句、文件清单说明、视频/音频淡入淡出与交叉位置解读）：

```powershell
# 校验格式与轨道（不生成工程）
python -B scripts/execute_timeline_edit.py --plan "<timeline_edit.json>" --check

# 1. 仅输出剪辑方案 + 人话操作指引
python -B scripts/execute_timeline_edit.py --plan "<timeline_edit.json>" --target plan --output "<新结果目录>"

# 2. 建立剪映草稿（先关闭剪映，在可视终端执行；写入字幕加 --srt；隔离测试可加 --drafts-root 与 --skip-register）
python -B scripts/execute_timeline_edit.py --plan "<timeline_edit.json>" --target jianying --srt "<精剪.srt>" --output "<新结果目录>"

# 3. 建立 ADu 工程（在线提交加 --mep-dir "<ADu协作目录>"）
python -B scripts/execute_timeline_edit.py --plan "<timeline_edit.json>" --target adudir --output "<新结果目录>"

# 4. FFmpeg 直接剪辑出片（需要烧录字幕加 --burn-srt "<精剪.srt>"）
python -B scripts/execute_timeline_edit.py --plan "<timeline_edit.json>" --target ffmpeg --output "<新结果目录>"

# 同时生成剪映草稿和 ADu 工程
python -B scripts/execute_timeline_edit.py --plan "<timeline_edit.json>" --target both --output "<新结果目录>"
```

## 四、剪映与 ADu 工程核验要点

- **剪映草稿**：执行前先退出 `JianyingPro.exe`，在独立可视终端运行。构建器自动锁定画布和帧率、双写 `draft_info.json` 与 `draft_content.json` 并登记首页索引。可用 `python -B scripts/jy_vendor/draft_inspector.py --root "<草稿根>" summary --name "<草稿名>" --json` 复核轨道与片段数。
- **ADu 工程**：严格按 MEP 1 协议分批（每批 <= 100 ops）导入素材并提交时间线；先建音频轨再建视频轨，保证同轨片段不串轨；有淡入淡出时自动追加 `set(field="fade", value=[fade_in, fade_out])`。
- **FFmpeg 直接出片**：按 `timeline_edit.json` 直接裁切拼接视频、应用变速与双音轨交叉淡入淡出，导出 MP4 成片；默认不烧录字幕，传入 `--burn-srt` 时烧录硬字幕。

## 五、最终交付极简汇报模板（只报重点）

剪辑全部完成后，在对话中只输出以下 **5 行重点**（详细分镜与时间点已保存在 `操作指引与剪辑说明.md`，不在对话里贴整份 JSON、逐条字幕表或脚本日志）：

```markdown
### 制作完成
- **成片概况**：`原长 XXs → 成片 XXs`｜档位：`平衡型/紧凑型/人性化`｜倍速：`1.0x`｜人声音量：`1.0`｜视频 `X` 段
- **配乐概况**（有配乐时显示）：`《歌名》`｜音频 `X` 段（音量 `0.18`，含 `X` 处交叉淡入淡出 / `X` 处停顿留白）
- **交付位置**：`<剪映草稿名及路径 / ADu包路径 / MP4成片路径>`
- **配套文件**：精剪字幕 `.srt`｜纯净台词 `.txt`｜详细说明 `操作指引与剪辑说明.md`
```
